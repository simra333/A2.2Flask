# Power Automate Flow Tracker

A command-line based application designed to help developers and teams manage flows and log automation activities efficiently.

# Features

- Add and manage Solutions and Flows
- Assign developers to flows and update status
- View and filter flows by solution

# Tech Stack

- Python 3
  SQLite for local database storage
- Object-Oriented Programming
- Git/GitHub** for version control

# How to Use

1. Clone the repository
2. Run the main script
3. Follow the menu options to manage Solutions, Flows, Developers or view Flow Logs.
